Analyze a video

Queues an analysis job. Poll the job or subscribe to the webhook.

POST/v1/videos/analyze

Request

FieldTypeDescription
urlstring · requiredAny of the 1000+ supported sites.
qualitystringbest (default), 1080p, 720p, audio.
webhook_urlstringCalled once the job finishes.

Example

curl
curl -X POST https://api.theogalh.dev/v1/videos/analyze \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"url": "https://youtube.com/watch?v=dQw4"}'
202 · application/json
{
  "id": "an_8f2c",
  "status": "queued",
  "eta_seconds": 45
}

Errors

StatusCodeWhen
400unsupported_urlThe site isn't in the supported list.
429rate_limitedMore than 10 jobs queued.
