Swagger UI — FastAPI

Le thème complet est dans assets/swagger-theogalh.css — il rethème /docs aux couleurs du système :

main.py
from fastapi.openapi.docs import get_swagger_ui_html

@app.get("/docs", include_in_schema=False)
def docs():
    return get_swagger_ui_html(
        openapi_url="/openapi.json", title="theoapi — docs",
        swagger_css_url="/static/swagger-theogalh.css")
